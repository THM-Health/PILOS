# V1

## API response shape

Return JsonResource classes for domain entities and CRUD payloads. Use response()->json() only for auth flows, error/conflict responses, and small ad-hoc payloads (URLs, feature flags).

## API list pagination

Use length-aware paginate() for paginated index endpoints. Do not use simplePaginate() or cursorPaginate(). Page size comes from GeneralSettings::pagination_page_size (room index may accept per_page from the request).
